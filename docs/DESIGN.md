# 그럴 땐 어떻게? 설계 방향

## 1. 왜 이 게임인가

AI가 정답을 바로 알려 주는 시대에는 "정답을 외워서 맞히는 공부"의 가치가 줄어듭니다.
대신 아래 능력이 중요해집니다.

| 힘 | 뜻 | 게임 속 장치 |
|---|---|---|
| 살피는 힘 | 상황을 숫자와 사실로 확인 | 체온 재기, 위험 신호 살피기 |
| 알아보는 힘 | 모르던 방법 찾아내기 | **알아보기 선택지 → 단서 카드 → 새 선택지가 열림** |
| 확인하는 힘 | AI·인터넷 답을 그대로 믿지 않기 | AI 도우미가 일부러 틀린 말을 섞음, 광고 블로그와 공식 사이트 중 고르기 |
| 도움을 청하는 힘 | 누구에게, 어떻게 물을지 | 이웃, 119 상담, 병원에 솔직하게 사정 말하기 |
| 돌보는 힘 | 직접 해 보기 | 물수건, 동생 곁 지키기 |

게임은 점수를 매기지 않습니다. 엔딩마다 **이번에 쓴 힘**, **이런 방법도 있었어요**(놓친 단서), **같이 이야기해 봐요**(정답 없는 질문)를 보여 줍니다.

## 2. 장르: 비주얼 노벨 + 자원 시뮬레이션 + 탐색

- 비주얼 노벨: 인물, 대사, 분기 이야기로 몰입하게 함
- 자원 게이지: 시각, 가진 돈, 동생 컨디션, 내 마음(걱정). 선택마다 대가가 있어서 "정답 고르기"가 아니라 "무엇을 희생할지" 판단하게 됨
- 탐색: 선택지가 처음부터 다 보이지 않음. 알아내야 열림(잠김 선택지로 "더 알아볼 게 있다"는 걸 알려 줌)

## 3. 나이별 같은 이야기, 다른 깊이

| | 초등 1~3 | 초등 4~6 | 중학생 |
|---|---|---|---|
| 힌트 | 매 순간 다음 할 일 힌트 | 힌트 있음 | 없음 |
| 선택지 | 도움 청하기 중심, 혼자 밤길·택시 없음 | 검색, 출처 비교, 응급실·택시·걷기 | 같은 선택지 + 더 깊은 회고 질문 |
| 정보 | 119, 이웃, 미지근한 물수건 | + 응급의료법, 대불제도, 광고 구별 | + AI 답을 믿을 때와 확인할 때 구별 |

에피소드 하나를 나이별로 따로 만들지 않고, 대사·선택지에 `ages` 표시만 달아 한 파일에서 관리합니다.

## 4. 그림과 에셋: 무엇으로 만들까

| 방법 | 장점 | 단점 | 판단 |
|---|---|---|---|
| **Blender (3D)** | 같은 캐릭터를 여러 각도·장면에서 재사용, 일관성 최고 | 모델링·리깅·렌더 시간이 큼. 이야기 게임에서 3D의 이점이 작음 | 지금은 비추천 |
| **Three.js (웹 3D)** | 브라우저에서 3D 방 탐색 가능 | 휴대폰·학교 크롬북에서 무거움, 만드는 비용 큼. 학습 효과는 이야기와 선택에서 나옴 | 나중에 "방 안 물건 뒤지기" 같은 미니게임에만 |
| **Gemini 등 이미지 생성 AI (2D 일러스트)** | 배경·표정 차분을 빠르게, 싸게 대량 생산. 비주얼 노벨에 딱 맞음 | 캐릭터 얼굴·옷이 장면마다 달라지기 쉬움 | **추천 (주력)** |
| **코드로 그린 SVG** (지금 프로토타입) | 무료, 가볍고, 바로 수정 가능 | 표현력이 단순함 | 기획·검증 단계용 |

### 결정: 비주얼 노벨 레이어 + 이미지 생성 AI 2D 일러스트

화면을 배경, 캐릭터(표정 차분), 이벤트 CG, 휴대폰 화면, 대사창으로 나눠 겹칩니다(일본 노벨 게임, 유튜브 영상 편집과 같은 방식).
엔진은 이 구조로 바뀌었고, 진짜 그림은 `assets/manifest.js`에 등록만 하면 됩니다.
규격, 순서, 생성 문장은 [ART_PIPELINE.md](ART_PIPELINE.md)에 있습니다.

## 5. 엔진: 웹(HTML/JS)

- 휴대폰, 태블릿, 학교 크롬북 어디서나 링크 하나로 실행됩니다. 설치가 필요 없습니다.
- 에피소드는 데이터 파일 하나(`scenarios/*.js`)입니다. 작가는 대사와 분기만 쓰면 됩니다.
- 작가가 많아지면 Ink(inkle) 같은 이야기 스크립트 언어로 옮기는 것을 검토합니다. Ren'Py는 PC용이라 학교 보급에는 덜 맞습니다.

## 6. 다음 단계

1. 에피소드 늘리기: 길을 잃었을 때, 휴대폰·지갑 분실, 단톡방 괴롭힘을 봤을 때, 사기 문자, 첫 아르바이트 임금 체불, 화재
2. **AI 자유 응답 모드**: 선택지 대신 아이가 "나라면 이렇게 할래"를 직접 쓰면, AI가 그에 맞는 결과를 이야기로 이어 줍니다. 정답이 아예 없는 구조입니다. 위험한 행동·잘못된 정보를 막는 안전장치가 함께 필요합니다.
3. 보호자·교사용 회고 화면: 아이가 어떤 힘을 많이 쓰고 어떤 힘을 덜 쓰는지 보여 주기
4. 실제 정보 감수: 119, 응급의료포털, 달빛어린이병원, 대불제도 등 현실 정보는 출시 전에 전문가 확인

> 게임 속 의료·제도 정보는 교육용 이야기입니다. 실제 상황에서는 119(응급·의료 상담), 129(보건복지상담), 1388(청소년 상담)에 물어보세요.
